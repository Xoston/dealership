# Luxury Dealer — Информационная система автосалона премиум-класса

Веб-платформа **Luxury Dealer** представляет собой Single Page Application (SPA), разработанное для автоматизации процессов просмотра, фильтрации, продажи автомобилей и управления ролевым доступом. 

## Технологический стек

* **Frontend:** React 18, Axios, Framer Motion (анимации), CSS-модули.
* **Backend:** FastAPI (Python 3.11), REST API.
* **База данных:** PostgreSQL / СУБД с поддержкой реляционных связей.
* **Контейнеризация:** Docker, Docker Compose.

### Предварительные требования
Убедитесь, что у вас установлены `Docker` и `Docker Compose`.

### Пошаговая инструкция

1. **Клонируйте репозиторий проекта:**
```bash
   git clone [https://github.com/Xoston/luxury-dealer.git](https://github.com/Xoston/luxury-dealer.git)
   cd luxury-dealer
2. **Запустите сборку и развёртывание контейнеров:**
```bash
   docker-compose up --build

3.Проверьте работоспособность сервисов:
    Клиентская часть (Frontend): доступна по адресу http://localhost:3000
    Серверная часть (Backend API): доступна по адресу http://localhost:8000
    Интерактивная документация API (Swagger): доступна по адресу http://localhost:8000/docs

4.Остановка приложения:
    docker-compose down
